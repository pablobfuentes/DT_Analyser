# Weekly Review

`/review/weekly?week=YYYY-MM-DD` (NY week, Monday start).

Summary reuses dashboard stats, expectancy profit factor, R statistics, and a simple peak-to-trough drawdown on the week's daily P&L.

Pattern panels are labeled **Observed this week.** `[Open in Research Lab]` is a link with filters — not a second research engine.

Candidate rules are not promoted or edited from this page.
