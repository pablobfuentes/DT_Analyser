# Daily Review

`/review/daily?date=YYYY-MM-DD` (NY date).

Auto numbers come from existing Dashboard / Risk / Signal / Excursion services. No new P&L or R formulas.

Prompts are configuration text (not a migration). Answers are never generated.

`Complete Review` stores `completed_at` plus `metrics_snapshot_json`. Later trade corrections change live metrics only. Refreshing the snapshot is an explicit action.
